📄 Análise de Log HAR

ⓘ O que é um arquivo HAR?
HAR (HTTP Archive) é um log das requisições feitas pelo navegador. Ele permite analisar tempo de carregamento, erros HTTP, problemas de segurança e muito mais sem precisar acessar o servidor.

Como exportar o HAR do navegador

📗 Chrome / Edge
  1. F12 → aba "Network"
  2. Navegue pelo site
  3. Clique direito → "Save all as HAR"
🐟 Firefox
  1. F12 → aba "Network"
  2. Navegue pelo site
  3. Ícone de engrenagem → "Save All As HAR"
🌎 Safari
  1. Preferências → Avançado → "Show Develop menu"
  2. Develop → "Network" → navegue
  3. File → "Export HAR"

⇧ Enviar arquivo .har
